🏛️ Architecture & Overview

Core System

Orac Server is a standalone media aggregation, metadata indexing, and stream scraping engine designed to power the Liberator Kodi Addon.

How It Works

  • Headless Backend: Runs silently on Windows, Linux, or Docker container, maintaining local SQLite caches for ultra-fast metadata access without hitting external API rate limits.
  • Unified Scraping Engine: Aggregates torrent hashes, direct stream links, and Debrid cloud files simultaneously across configured scraper modules.
  • Fast Local IPC & Web API: Liberator communicates with Orac either via high-speed Unix/Windows named sockets (IPC) on the same machine, or via standard REST HTTP endpoints across your local home network.
💡 Tip: Running Orac Server on an always-on NAS or mini PC allows multiple Kodi boxes in your household to share the same indexed databases, watched status, and scraper configurations.

🔌 Connecting Liberator to Orac Server

Configuration

To connect the Liberator Kodi addon to your running Orac Server instance:

Step-by-Step Connection

  1. Open Kodi and navigate to Liberator → Tools → Settings.
  2. Select the General / Server tab.
  3. Configure the server host details:
    Orac Server IP: 192.168.1.100 (or 127.0.0.1 if running on the same PC) Orac Server Port: 8000 (default)
  4. Toggle Enable Orac Server Connection to ON.
  5. Click OK and verify connectivity in the Liberator status indicator.
⚙️ Port Note: If running Orac in Docker or a custom environment, ensure port 8000 (or your chosen port) is forwarded and reachable across your local subnet.

🧭 Discover Studio & External Indexes

Discovery

The Discover Studio tab allows you to query TMDb's global catalog with deep filters (genres, release years, vote score, watch providers) and save queries directly as External Indexes.

Creating & Managing External Indexes

  • Live Query: Set your target media type (Movies or TV Shows), select genres, minimum score, and release year range, then click Discover.
  • Save as Index: Click 📑 Save as Index, give your index a unique name (e.g. Top Netflix Sci-Fi), and click Save.
  • Liberator Integration: Saved external indexes instantly appear in Liberator under the Discover / Indexes category menu!
  • Manage & Delete: Open the External Indexes tab to view all created queries, test them with live preview results, or delete outdated indexes.
💡 Provider Filtering: Selecting providers like Netflix, Disney+, Prime Video, or Apple TV+ queries TMDb's localized catalog to find titles available on those platforms.

📑 Internal Library Indexes

Library

While External Indexes query TMDb online, Internal Indexes run against your local cached library in movies_static_cache.db and tvshows_static_cache.db.

Key Advantages

  • Instant Browsing: Sub-millisecond response times because all metadata, cast, ratings, and artwork URLs are stored locally in SQLite.
  • Custom Filters: Filter your library by status (e.g. Continuing, Ended), release decade, watched progress, or genres.
  • Offline Capability: Browse your media collection even when external APIs or internet connections are temporarily unavailable.

⚡ Multi-Debrid Scrapers & Cloud Resolving

Scraping

Orac includes high-performance scrapers supporting the leading premium Debrid providers.

Supported Services

  • Real-Debrid: Fast cached torrent resolving and hoster links.
  • Premiumize.me: Cloud inspection, direct stream links, and RSS downloading.
  • TorBox / OffCloud / EasyDebrid: Direct cloud stream resolutions.
  • AIOStreams: External multi-indexer integration.

Scraper Metrics & Prioritization

The dashboard continuously benchmarks scrapers based on response latency, stream quality (4K, 1080p, HDR/DV), and scrape success rate, ensuring the fastest sources are resolved first.

🔄 Account Synchronization (Trakt / Simkl)

Sync Engine

Orac synchronizes watch history, ratings, collection items, and custom lists across platforms.

Supported Platforms

  • Trakt: Full two-way synchronization of watched movies, episodes, collection items, and custom lists. Air dates and metadata are enriched with extended detail.
  • Simkl: Fast token-based sync for anime, TV shows, and movie watchlists.
  • MDBList: Dynamic list synchronization for curated trending and popular media lists.
  • PunchPlay: OAuth device flow integration for personal lists and public trending catalog.
⚠️ Automatic Background Worker: Orac runs periodic hourly sync tasks in the background so your watched status and next episodes are always up to date.

🛠️ Diagnostics, Database Maintenance & Health

Maintenance

Use the Diagnostics panel at the top of the Help tab to monitor server health in real-time.

Key Tools

  • 🔄 Health Check: Tests live API connectivity and latency to TMDb, Trakt, and Fanart.tv.
  • 🧹 Vacuum Databases: Executes SQLite VACUUM across all database files (movies, shows, lists, config) to reclaim unused disk space and rebuild indexes for optimal performance.
  • Integrity Check: Performs PRAGMA quick_check on every database file to ensure no data corruption has occurred.
