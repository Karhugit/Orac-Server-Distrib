Liberator & Orac Architecture Guide
1. Connecting Liberator to Orac Server
Orac operates as a headless backend service. Liberator can communicate with Orac via HTTP API (for remote servers/docker) or Local IPC socket (when running on the same host).
Liberator Settings → General → Orac Server IP: <YOUR_ORAC_IP> | Port: 8000
2. External Indexing vs. Internal Indexing
  • External Indexes: Query TMDb directly based on release year, score, provider (e.g. Netflix, Disney+), and genres. Saving an external index in Discover Studio makes it instantly appear in Liberator's Discover menus!
  • Internal Indexes: Filter and browse movies and TV shows that are already indexed in your local SQLite databases.
3. Multi-Debrid Scraping & Cloud Resolving
Orac aggregates real-time stream links from multiple scrapers across Real-Debrid, Premiumize, TorBox, OffCloud, and EasyDebrid. Scrapers are benchmarked with live success scoring and prioritized automatically.
